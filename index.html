Interactive Elements

In-text link

CSS selector:

a

Sample code:

<p>Try our handmade and daily fresh <a href="#">different type of bread</a> for you to explore.</p>

Rendered element:

Try our handmade and daily fresh different type of bread for you to explore.

Navigation Link

CSS selector:

.button-nav

Sample code:

<a href="#" class="button-nav">Order Now</a>

Rendered element:

Order Now

Submit/Reset Buttons

CSS selector:

button[type="submit"], button[type="reset"]

Sample code:

<form>
  <button type="submit">Submit</button>
  <button type="reset">Reset</button>
</form>

Rendered element:

Text Input Field with Label

CSS selector:

label + input[type="email"]

Sample code:

<label for="email">Email Address</label>
<input type="email" id="email">

Rendered element:

Radio Button with Label

CSS selector:

input[type="radio"] + label

Sample code:

<input type="radio" id="hot" name="temp">
<label for="hot">Reheat before delivery</label>

Rendered element:

Image as a Link

CSS selector:

a img

Sample code:

<a href="#">
  <img src="assets/bread.jpeg" alt="A loaf of bread">
</a>

Rendered element:

Combined Elements

Main Navigation

CSS selector:

.main-nav li a

Sample code:

<nav>
  <ul class="main-nav">
    <li><a href="#">Home</a></li>
    <li><a href="#">Menu</a></li>
    <li><a href="#">About</a></li>
    </ul>
  </nav>

Rendered element:

  • Home
  • Menu
  • About

Product/Service Listing

CSS selector:

.product

Sample code:

<article class="product">
  <img src="assets/bread.jpeg" alt="Bread Loaf">
  <h4>White Bread Loaf</h4>
  <p class="price">$5.25</p>
  <a href="#">View Details</a>
</article>

Payment Form

CSS selector:

form, fieldset, label, input, button

Sample code:

<form>
  <label for="fullname">Full Name</label>
  <input type="text" id="fullname">

  <label for="cardnumber">Card Number</label>
  <input type="text" id="cardnumber">

  <fieldset>
    <legend>Payment Method</legend>
    <input type="radio" id="visa" name="payment">
    <label for="visa">Visa</label>
    <input type="radio" id="mastercard" name="payment">
    <label for="mastercard">Mastercard</label>
  </fieldset>

  <button type="submit">Submit Payment</button>
</form>

Rendered element:

Payment Method

Checkout Cart

CSS selector:

table, th, td

Sample code:

<table>
  <thead>
    <tr><th>Item</th><th>Cost</th></tr>
  </thead>
  <tbody>
    <tr><td>White Bread Loaf</td><td>$5.25</td></tr>
    <tr><td>Baguette</td><td>$3.50</td></tr>
  </tbody>
  <tfoot>
    <tr><th>Total</th><th>$8.75</th></tr>
  </tfoot>
</table>

Rendered element:

ItemCost
White Bread Loaf$5.25
Baguette$3.50
